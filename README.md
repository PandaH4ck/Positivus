# Positivus - Digital Agency Landing Page
[Live Demo](https://pandah4ck.github.io/Positivus/)

A responsive landing page built from a Figma design to practice modern CSS layouts and Vanilla JavaScript.

## 🛠 Tech Stack
- HTML5
- CSS3 (Flexbox, custom properties)
- Vanilla JavaScript

## ✨ Key Features
- **Custom JS Slider:** Built completely from scratch without third-party libraries. Handles responsive offsets and seamless transitions.
- **Dynamic SVGs:** Programmatic color switching of SVG elements based on the active slider state.
- **Modern CSS Solutions:** Implemented purely CSS-based geometric shapes (like dialogue bubbles) using pseudo-elements.
- **Clean Git History:** Maintained a professional commit history using interactive rebase and squash techniques.

## 🚀 Run Locally
1. Clone the repo: `git clone https://github.com/PandaH4ck/Positivus.git`
2. Open `index.html` in your browser or use VS Code Live Server.
